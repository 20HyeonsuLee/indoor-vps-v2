## rule
- **WCAG 2.1 AA** 기준. 모든 사용자 인터랙션은 키보드만으로 가능해야 한다.
- **semantic HTML 우선**. `<button>`/`<a>`/`<nav>`/`<main>`/`<header>` 의미 그대로. `<div onClick>` 금지.
- 인터랙티브 요소는 `role` + `aria-*` 또는 native element 사용:
  - 버튼은 `<button>` (form submit 외에는 `type="button"` 명시)
  - 링크는 `<a href>` (라우팅은 next/link)
  - form 컨트롤은 `<label>` 연결 (`htmlFor` 또는 wrap)
- **키보드 네비**:
  - Tab/Shift+Tab: focus 이동
  - Enter/Space: 버튼·링크 활성
  - Esc: modal/dropdown 닫기
  - Arrow: list/menu/tab 내부 이동
  - Modal/Dialog: focus trap + 닫으면 trigger로 focus 복귀
- **focus 시각화**: `focus-visible` ring 유지. `outline: none` 금지 (대체 표시 있을 때만).
- **color contrast**:
  - 텍스트 4.5:1 (일반), 3:1 (large 18px+)
  - UI 컴포넌트·focus indicator 3:1
  - 색만으로 의미 전달 금지 (icon/text 보조)
- **screen reader**:
  - icon-only 버튼은 `aria-label` 필수
  - 동적 변경(error, toast)은 `aria-live` (polite/assertive)
  - 페이지 제목은 `<title>` + 적절 heading 계층 (`h1` 1개, h2-h6 순서)
  - skip link (`<a href="#main">메인 내용 건너뛰기</a>`) 권장
- **form a11y**:
  - 모든 input에 label
  - error는 `aria-invalid` + `aria-describedby`로 메시지 연결
  - required는 `aria-required` 또는 native `required`
- **이미지/미디어**:
  - `<img alt>` 의미 있는 텍스트. 장식이면 `alt=""`
  - video는 caption + transcript
  - 자동 재생 비활성 또는 mute default
- **모션**:
  - `prefers-reduced-motion` 존중. 큰 모션은 차단 또는 단순화
  - flashing > 3Hz 금지 (간질 유발)
- **타겟 크기**: 터치 영역 최소 44x44 px.
- **언어**: `<html lang="ko">` 명시. 부분 다른 언어는 `<span lang="en">`.

## 자동 검증
- ESLint: `eslint-plugin-jsx-a11y` (recommended preset)
- 단위 테스트: `jest-axe` (Vitest 호환) — 컴포넌트 마운트 후 axe 검사
- E2E: `@axe-core/playwright` — 페이지 단위 axe 검사
- Lighthouse a11y 점수 ≥ 95
- 수동: 키보드만으로 모든 flow / 스크린리더(VoiceOver, NVDA) 점검

## forbidden
- `<div onClick>` 인터랙티브 처리 (semantic element 사용)
- `outline: none`만 두고 focus 대체 표시 X
- icon-only 버튼에 `aria-label` 누락
- form input에 label 누락 (placeholder만으로 대체 X)
- color만으로 상태 표시 (success/error를 색만으로)
- 자동 재생 video + 소리
- focus trap 없는 modal
- heading 계층 깨짐 (h1 → h3 skip)
- `tabindex > 0` (tab 순서 강제 — 0 또는 -1만)
- `role="button"`을 `<div>`에 + keyboard handler 누락
- `aria-*` 속성 잘못 사용 (`aria-label`을 visible text 있는 곳에 중복)
- 접근성 lint 무시 (`// eslint-disable jsx-a11y`)
- 모든 모션을 `prefers-reduced-motion` 무시하고 강제
- 타겟 크기 44px 미만 (모바일)
