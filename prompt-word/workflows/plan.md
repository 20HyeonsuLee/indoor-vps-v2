## 목적
draft 시작 전 **목적·독자·범위·구조**를 확정.

## 절차
1. **목적 1줄**
   - "이 문서로 독자가 무엇을 알고·결정·행동하게 할 것인가?"
2. **독자 분석**
   - 누구 (직책·도메인·지식)
   - 사전 지식 수준
   - 결정권자 vs 정보 수령자
3. **범위·non-goal**
   - 다루는 주제
   - 다루지 않는 것 (의도적)
4. **문서 종류 결정** (`structure/document`)
5. **구조 초안** (`structure/heading`)
   - heading 계층 (제목 1·2·3...) 줄거리
   - 각 섹션 무엇을 담을지 1줄
6. **참조·출처 수집**
   - 인용할 출처 list
   - 데이터·통계 출처
   - 인용 스타일 결정 (`structure/reference`)
7. **template 선택** (`office/template`)
   - 사내 standard `.dotx`
8. **plan 검토**
   - 요청자·stakeholder에 outline 공유
   - 범위·구조 합의

## 산출물
- plan 1 page (목적·독자·범위·종류·구조 outline)
- 인용 source list

## 금지
- plan 없이 draft
- 목적 모호
- 독자 분석 누락
- 범위 무한
- 종류 모호 (보고서·제안서 혼재)
- 구조 outline 없이 작성
- 인용 source 사전 수집 안 함
- template 안 쓰고 백지에서 시작
