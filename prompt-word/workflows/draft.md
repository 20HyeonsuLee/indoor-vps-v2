## 목적
plan에서 정한 구조를 본문으로 채움.

## 절차
1. **template에서 새 문서**
   - 사내 standard .dotx (`office/template`)
   - 표지 작성 (제목·작성자·날짜·버전)
2. **목차 자리 자동 생성**
   - `참조 > 목차 > 자동 목차` (heading 기반)
3. **heading 골격 작성**
   - plan의 outline을 heading 1·2·3...으로
   - 비어 있는 heading만 먼저 (전체 구조 가시화)
4. **섹션별 본문 작성**
   - topic sentence 우선 (각 단락 첫 문장)
   - 근거·예시·detail 추가
   - 표·그림·list 적용
   - 인용·각주 추가
5. **요약·결론 작성**
   - 본문 완료 후 (top-down 가능)
   - executive summary는 표지 다음에
6. **참고문헌 정리**
   - Word 인용 기능 또는 EndNote/Zotero
7. **field update**
   - 목차·캡션·cross-ref 갱신 (`F9`)
8. **자체 1차 점검**
   - 맞춤법 (F7)
   - 일관성 (용어·표기)
   - field stale 확인

## 작성 팁
- 첫 draft는 빨리 (perfectionism 차단). 나중에 다듬기.
- 어려운 섹션은 outline 먼저, 본문 나중.
- 매일 단위·섹션 단위 commit (cloud 자동저장).
- 인용·출처는 작성 시점에 같이 (나중 찾기 어려움).
- 직접 서식 X — style 사용.

## 금지
- template 안 쓰고 작성
- heading style 무시하고 폰트 키우기
- 직접 목차 작성
- 인용 후 출처 표시 미루기
- list·표·캡션 수동 번호
- 일관성 안 보고 자유 작성
- draft 시작 전 plan 없이
- 인용 source 사전 수집 없이 (작성 중 검색 시간 손해)
- field update 누락
