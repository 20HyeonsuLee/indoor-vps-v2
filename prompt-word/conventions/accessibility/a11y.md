## rule
- **WCAG 2.1 AA** 기준 (가능한 한). 공공 문서는 의무.
- heading 계층 (Word style)으로 구조화 — 스크린리더 navigation.
- 그림·차트·표에 **alt text** (`figure 우클릭 > 대체 텍스트`).
- 색만으로 의미 전달 X (icon·label 보조).
- 본문 색은 dark on light contrast 4.5:1.
- 폰트 크기 ≥ 10pt 본문, ≥ 18pt 큰 텍스트 (`design/typography`).
- 표는 헤더 행 명시 (스크린리더 인식).
- 링크 텍스트는 의미 있게 ("여기 클릭" X → "회사 홈페이지").
- 목차·페이지 번호 자동 (스크린리더 인식).
- reading order 명확 (옆 column·callout 등 복잡 layout 주의).
- 약어는 첫 등장 풀이 (`writing/writing`).
- 외국어 단락은 언어 표시 (`검토 > 언어`).

## rule (Word 접근성 검사)
- `검토 > 접근성 검사` 활성.
- issue를 다 해결 후 final.
- 자동 검출: alt 누락·heading skip·표 헤더 누락·color contrast.

## rule (PDF export)
- **태그된 PDF** export (스크린리더 reading order).
- 북마크 (heading 기반) 생성.
- form field 접근성 (label).

## rule (인쇄)
- 흑백 인쇄 미리보기로 색 의존 점검.
- 큰 글씨 버전 별도 (시각 약자).

## forbidden
- alt text 누락
- 색만으로 의미 표시
- contrast WCAG 미달
- 본문 < 10pt
- heading 직접 폰트 키우기 (style 사용)
- 표 헤더 미지정
- "여기 클릭" 모호 link
- 복잡 layout으로 reading order 깨짐
- 약어 풀이 누락
- 외국어 단락 언어 표시 누락
- Word 접근성 검사 무시
- 태그 없는 PDF export
- form field label 누락
