## rule
- 학술 문서 (논문·thesis·연구 보고서).
- 표준 IMRaD 구조:
  - **Introduction**: 배경·문제·연구 질문·기여
  - **Methods**: 재현 가능한 방법
  - **Results**: 데이터 (해석 X — 객관)
  - **Discussion**: 해석·한계·시사점
- 또는 분야별 구조 (학회·저널 guide 따름).
- 초록 (abstract) 150~300 단어. stand-alone.
- 키워드 5~7개.

## rule (인용)
- 모든 외부 출처 명시. 표절 절대 X.
- 인용 스타일 (APA/MLA/Chicago/IEEE/Vancouver) 분야 표준 따름.
- 참고문헌 자동 관리 (Word `참조` 또는 EndNote·Zotero·Mendeley).
- DOI 우선. URL은 archive (Wayback) 권장.
- self-citation 신중 (남용 X).

## rule (객관성)
- 1인칭 (`I`/`we`) 사용은 분야별 (사회과학 OK, 일부 자연과학은 수동태 선호).
- 주관 표현 절제 ("느낀다", "생각한다" → "관찰된다", "시사한다").
- hedging 적절 ("may", "could", "suggests" — 단정보다 조심).
- 결론은 데이터 범위 안에서.

## rule (수식·표·그림)
- 수식은 Word equation editor.
- 표·그림 자동 번호 + 캡션 (`content/figure.md`, `content/table.md`).
- 본문에서 모든 표·그림 cross-reference.

## rule (재현성)
- 데이터·코드는 supplementary 또는 별 저장소 (Zenodo·OSF·GitHub).
- DOI 부여 권장.
- 코드는 license 명시.
- 실험 환경 detail (OS·버전·hardware).

## rule (윤리)
- IRB 승인 (인간 대상).
- conflict of interest 명시.
- 저자 기여 명시 (CRediT taxonomy).
- 표절 검사 (Turnitin·Copyleaks).

## forbidden
- 표절 (paraphrase도 출처 필수)
- 데이터 조작·선택적 보고
- self-plagiarism (이전 자기 글 출처 없이 재사용)
- 결론을 데이터 범위 밖으로 확장
- 인용 스타일 혼용
- 참고문헌 수동 관리 (Word/EndNote 사용)
- 1인칭 무분별 (분야 표준)
- 주관 형용사 ("훌륭한", "혁신적")
- 재현 불가능한 방법 (detail 누락)
- 데이터·코드 비공개 (open science 권장)
- 저자 기여 모호
- IRB 누락 (인간 대상 연구)
- 익명 review 무시 (코멘트 응답 의무)
