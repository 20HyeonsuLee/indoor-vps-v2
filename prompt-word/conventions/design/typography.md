## rule
- font family **2종 이하** (본문 + heading. mono는 코드 단락만).
- 본문 font:
  - 한국어: **맑은 고딕 / Pretendard / 함초롬바탕** (serif) 등 안전
  - 영문: Calibri / Arial / Times New Roman / Georgia
- heading은 본문과 같거나 sans-serif 한 단계 위.
- 크기 (A4 기준):
  - 제목 1: 18~22pt bold
  - 제목 2: 14~16pt bold
  - 제목 3: 12~13pt bold
  - 본문: **10~12pt** (한국어 11pt 표준, 영문 11~12pt)
  - 캡션·footer: 9~10pt
  - 각주: 9~10pt
- line spacing (행간):
  - 본문 1.15~1.5 (한국어 1.5 권장 가독)
  - heading 1.2
- 문단 간격: 본문 6~12pt (style spacing)
- 정렬:
  - 한국어: 양쪽 정렬
  - 영문: 왼쪽 정렬 권장
- weight: heading bold, 본문 regular. light는 큰 글씨만.
- italic: 외래어·책 제목·강조 (절제).
- bold: 핵심 단어 (절제).
- 영문·한글 혼용 시 폰트 fallback 설정.

## rule (Word 기능)
- 폰트 변경은 **스타일** 통해서 (직접 변경 X).
- 다단 단락 (`레이아웃 > 단`)은 분야별 (학술·뉴스레터).
- 자간·행간은 단락 단위로 설정.

## forbidden
- font family 3종 이상 혼용
- 본문 < 10pt
- 한국어 line spacing < 1.15 (가독 ↓)
- 직접 폰트 키워서 heading 흉내 (스타일 사용)
- ALL CAPS 긴 텍스트
- underline (link 외)
- 글자 shadow·outline·3D
- 본문에 decorative font (script·handwriting)
- 한·영 폰트 mismatch (높이·정렬 깨짐)
- font fallback 미설정 (다른 PC 깨짐)
- bold·italic 남발
- 색 사용 분산 (본문 검정 통일, 강조 색 제한)
