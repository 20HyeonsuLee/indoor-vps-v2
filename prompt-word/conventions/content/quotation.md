## rule
- 직접 인용은 **단어 그대로** + 큰따옴표 + 출처.
- 짧은 인용 (< 40 단어 / 4 줄): inline 큰따옴표
- 긴 인용 (≥ 40 단어 / 4 줄): block quote (들여쓰기 + 큰따옴표 없음).
- 변형은 명시:
  - 생략: `[...]`
  - 추가: `[브래킷]`
  - 강조: `[강조 추가]`
- 원문 오류는 `[sic]` 표시.
- 외국어 인용:
  - 원문 + 번역 병기 (학술)
  - 번역만 + 출처 (실용)
- 인용 후 분석·comment 추가 ("citation 하고 던지지" X — 의미 부여).

## rule (paraphrase)
- 원문을 자기 단어로 재진술. 단 의미 보존.
- paraphrase도 출처 필수 (직접 인용과 동일).
- 한 단락 50%+ paraphrase면 직접 인용 또는 출처 강조.

## rule (저작권)
- fair use 범위 안에서만.
- 학술: 인용 + 출처 = 합법 (그러나 분량 제한 있음).
- 상업·홍보: 별 허가 필요.
- 이미지·도표는 텍스트보다 엄격 (출처 + 라이선스 확인).

## forbidden
- 직접 인용 변형 없이 표기 (단어 바꾸면서 따옴표 유지)
- 출처 없는 인용 (표절)
- paraphrase에 출처 누락 (paraphrase도 표절)
- 인용만 나열 후 분석 0 (의미 부여 누락)
- 긴 인용 inline (block quote)
- 큰따옴표·작은따옴표 무질서
- 외국어 원문만 (번역 또는 의미 설명 필요)
- 저작권 침해 분량 (fair use 초과)
- 인용 안 한 source를 참고문헌에 (역도 마찬가지)
