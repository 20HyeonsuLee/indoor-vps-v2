## rule
- 표는 **비교가 다차원**일 때 사용 (1차원 비교는 list).
- 표 캡션: 위 (`표 1. 캡션`), 자동 번호 (`참조 > 캡션`).
- 첫 행은 **헤더** (Word `테이블 디자인 > 머리글 행`). 굵게·배경색·반복.
- 페이지 넘어가면 헤더 자동 반복 (Word `테이블 속성 > 행 > 머리글 행`).
- 정렬:
  - 텍스트: 왼쪽
  - 숫자: 오른쪽
  - 헤더: 가운데 또는 왼쪽
- 빈 cell은 `—`, `N/A`, 또는 빈 칸 (의미 일관).
- 행·열 너비는 콘텐츠에 맞춤. 자동 조정 활용.
- 표 안 폰트 크기 본문보다 1pt 작게 가능 (가독 유지).
- 표 줄 (border): 헤더 아래 + 외곽 + 행 분리선. grid 가득 X.
- 큰 표는 sideways (landscape page) 또는 부록.
- 표 cell 안 list·복잡 구조 X (table을 layout 도구로 X).

## 크기 가이드
- 권장: ≤ 8 column × ≤ 20 row.
- 초과 시: 분할·축약·부록 이동·landscape.

## rule (Word 표 기능)
- `삽입 > 표` (그리드).
- Excel paste-link 가능 (live link).
- 표 스타일은 sheet 통일 (`테이블 디자인` 갤러리에서 1개).
- 표 안 cross-reference 활용 (`참조 > 상호 참조`).

## forbidden
- 표를 layout 도구로 사용 (text 정렬을 위해)
- 헤더 행 미지정 (a11y·반복 안 됨)
- column 8개 초과 (가독 ↓)
- row 20개 초과 (부록 이동)
- cell border grid 가득 (visual noise)
- 표 안 cell 빈 채로 (의미 명시 — `—`)
- 캡션 누락
- 캡션을 표 아래 (위가 표준)
- 출처 누락
- 표 안 폰트 size 너무 작음 (< 9pt)
- 표 안 list·중첩 표
- 정렬 무질서 (숫자 좌측 정렬 등)
