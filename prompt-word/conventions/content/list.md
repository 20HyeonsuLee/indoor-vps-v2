## rule
- list는 **list가 의미 있는 정보**에만 (산문 분해 X).
- 종류:
  - **순서 list (번호)**: 순서·우선순위·단계
  - **순서 없는 list (글머리표)**: 동등 항목
  - **정의 list**: 용어 + 설명
- Word `홈 > 단락 > 글머리표/번호 매기기` 사용. 수동 X.
- 항목 수 권장: 3~7개. 너무 적으면 list 의미 X, 너무 많으면 grouping.
- 모든 항목 **parallel 구조** (모두 명사 / 모두 동사 명령형 / 모두 같은 길이).
- 항목 1줄 권장. 긴 설명은 sub-bullet.
- 중첩은 2 단계까지. 3 단계 이상은 표나 별 섹션.
- 항목 끝 punctuation 일관 (모두 마침표 또는 모두 없음).
  - 영문: 완전한 문장이면 마침표
  - 한국어: 짧은 명사구는 마침표 없음 권장
- 번호 list는 자동 (Word 기능). 직접 "1." "2." X.

## forbidden
- 산문을 점 찍어 분해
- parallel structure 위반
- 항목 1개 list (list X)
- 항목 10개 초과 (grouping 또는 표)
- 3 단계 이상 중첩
- 항목 끝 punctuation 무질서
- 수동 번호 매기기
- list 안 list 안 list (구조 깊어짐)
- 같은 단어로 모든 항목 시작 ("우리는...")
- 너무 추상적 항목
- list 사이에 무관한 본문 끼움
