## rule (인용 방식)
- 문서 종류별 인용 스타일 1개 채택, 일관 사용:
  - **APA** (사회과학): `(Lee, 2024)` + 참고문헌
  - **MLA** (인문): `(Lee 23)` + Works Cited
  - **Chicago** (인문/역사): 각주 + 참고문헌
  - **IEEE** (공학): `[1]` + 참고문헌 번호순
  - **한국어 학술**: 분야 표준 (학회 가이드)
- 인용은 모든 외부 출처 (책·논문·웹·데이터·이미지). 자기 글 외 정보는 출처 명시.
- 직접 인용 (큰따옴표 + 출처) vs 간접 인용 (paraphrase + 출처).
- 직접 인용은 단어 그대로. 변형 시 `[...]` 표시.
- 긴 인용 (40 단어/4 줄 이상)은 들여쓰기 block quote.

## rule (각주·미주)
- Word `참조 > 각주/미주` 사용. 수동 X.
- 각주: 같은 페이지 하단. 본문 보조 설명·짧은 출처.
- 미주: 문서 끝. 긴 설명·다수 출처.
- 1 문서 = 한 방식 일관 (각주 vs 미주).
- 각주 번호는 자동.

## rule (참고문헌)
- 문서 끝 별 섹션 (`참고문헌` 또는 `References`).
- 인용 스타일 표준 따름.
- 정렬: 저자 가나다/알파벳 순 (또는 IEEE는 본문 등장 순).
- 모든 인용 항목이 참고문헌에 있어야 함 (역도 마찬가지 — 인용 안 한 항목 X).
- 웹 출처는 접근일 명시 (`(2026-05-24 접근)`).
- DOI 우선 (논문). URL은 archive (Wayback) 권장.
- Word `참조 > 인용 및 참고문헌` 기능 활용 (자동 관리).

## rule (그림·표 캡션)
- Word `참조 > 캡션 삽입` 사용 (자동 번호).
- 그림: `그림 1. 캡션 텍스트` (그림 아래)
- 표: `표 1. 캡션 텍스트` (표 위)
- 캡션은 stand-alone 이해 가능 (본문 안 보고도 의미 잡힘).
- 본문에서 `(그림 1 참조)` 또는 `그림 1과 같이...`로 인용 (자동 참조 사용).
- 출처 인용은 캡션 끝 또는 footer.

## rule (cross-reference)
- 섹션·그림·표·각주 본문 참조는 **Word cross-reference 기능** (자동 갱신).
- "위 그림" 같은 모호한 표현 X. "그림 3 참조".

## forbidden
- 출처 없는 외부 정보 인용
- 인용 스타일 혼용
- 각주·미주 수동
- 참고문헌 누락 인용
- 인용 안 한 참고문헌 항목
- 웹 출처 접근일 누락
- 캡션 수동 번호
- 본문에서 "위 그림" / "아래 표" 모호한 참조 (cross-ref 사용)
- 표 캡션을 표 아래에 (위가 표준)
- 직접 인용을 paraphrase로 표시
- 긴 인용 (4줄+)을 inline (block quote)
- DOI/URL 없는 학술 인용
