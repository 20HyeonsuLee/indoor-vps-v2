## rule
- heading은 **Word 스타일 (제목 1·2·3...)** 적용. 직접 폰트 키우기 X.
- 계층 일관:
  - 제목 1: 장 (Chapter) — 페이지 시작
  - 제목 2: 절 (Section)
  - 제목 3: 소절 (Subsection)
  - 제목 4: 항 (보통 여기까지)
  - 제목 5+ 권장 X (구조 너무 깊음)
- 한 번에 한 단계만 내려간다 (제목 1 → 제목 3 skip X).
- 번호 자동 (Word `다단계 목록`). 수동 번호 X.
- 번호 형식 (한국어 보고서 표준):
  - 1. 2. 3. (제목 1)
  - 1.1 1.2 (제목 2)
  - 1.1.1 (제목 3)
  - (1)(2)(3) (제목 4)
  - 또는 한자/한글 (Ⅰ. Ⅱ. / 가. 나.)
- heading 텍스트는 명사구 또는 짧은 문장. 12 단어 이하.
- 같은 계층은 parallel 구조 (모두 명사 / 모두 동사 명령형).
- 목차는 heading 기반 자동 생성.
- heading 다음 단락은 1 빈 줄 (스타일 spacing으로).

## forbidden
- heading을 본문 폰트 키우기로 흉내 (스타일 사용)
- 계층 skip (제목 1 → 제목 3)
- 6 단계 이상 깊이
- 수동 번호 (자동 사용)
- heading 안 긴 문장 (12 단어 초과)
- 같은 계층에 parallel 위반 (명사 + 동사 혼용)
- 목차 수동 작성
- heading 안 punctuation 끝 (마침표 보통 X)
- heading 다음 빈 단락 (style spacing으로)
- heading 만 있고 본문 없는 섹션
- 같은 heading 문구 중복 (검색·navigation 혼동)
