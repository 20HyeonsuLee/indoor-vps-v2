## rule
- 모든 문서는 **목적·독자·범위** 3개부터 정한다.
- 문서 종류별 표준 구조:

| 종류 | 핵심 섹션 |
|---|---|
| **보고서** (report) | 표지 · 요약(Executive Summary) · 본문 · 결론 · 권고 · 부록 |
| **제안서** (proposal) | 표지 · 개요 · 문제 · 솔루션 · 일정 · 비용 · 팀 · 부록 |
| **매뉴얼** (manual) | 표지 · 목차 · 개요 · 사용법(단계별) · troubleshooting · FAQ · index |
| **메모** (memo) | 수신·발신·날짜·제목 · 본문 1~2 page · action items |
| **학술 논문** (academic) | 표지 · 초록 · 서론 · 본문(방법·결과·토의) · 결론 · 참고문헌 · 부록 |
| **요건명세** (spec/SRS) | 개요 · 범위 · 용어 · 기능 요건 · 비기능 요건 · 사용자 시나리오 · 부록 |
| **계약서** | 당사자 · 정의 · 조항 · 효력·해지 · 서명 |
| **공문** | 수발신 · 제목 · 본문 · 첨부 |

- **표지**에 필수: 제목·작성자·날짜·버전·기관(필요 시).
- **요약**(executive summary)은 본문 마지막에 작성하지만 위치는 앞 (top-down).
- 본문은 heading 계층 (`structure/heading.md`).
- 부록은 본문에 비핵심 detail (큰 표·원본 데이터·법적 문서).
- 페이지 번호 (1부터 또는 i, ii ...). 표지는 보통 미표시.
- 머리말·꼬리말로 문서 제목·버전·작성자 표시.
- 목차는 자동 생성 (Word `참조 > 목차`). 수동 X.

## 길이 가이드
| 종류 | 권장 길이 |
|---|---|
| memo | 1~2 page |
| 보고서 (executive) | 5~10 page + 부록 |
| 보고서 (technical) | 15~50 page |
| 제안서 | 10~30 page |
| 학술 논문 | 분야 표준 (보통 8~25 page) |
| 매뉴얼 | 범위 따라 (10~100+) |

## forbidden
- 목적·독자·범위 없이 작성 시작
- 종류 모호 (보고서·제안서·메모 섞임)
- 표지 누락 (memo 제외)
- 요약 누락 (보고서·제안서)
- 부록을 본문에 inline
- 페이지 번호 누락
- 수동 목차 (자동 생성 사용)
- 같은 문서에 종류 변경 (한 종류 일관)
- 권장 길이 무시 (executive에 100 page)
- 부록에 sensitive 데이터 안 마스킹
