## rule (검토 6 축)
1. **목적**: 독자가 무엇을 얻을 것인가? 명확?
2. **구조**: heading 계층·목차·섹션 흐름 일관?
3. **콘텐츠**: 사실·출처·인용·논리?
4. **언어**: 맞춤법·띄어쓰기·문법·톤?
5. **a11y**: alt·heading·contrast·reading order?
6. **품질**: 표·그림·페이지번호·머리말·field update?

## 단계별 review
- **author self-review** (draft 후 24h 후)
  - 소리내어 읽기 (어색한 문장 발견)
  - 6 axis self-check
  - 분량 30% cut 시도
- **peer review** (≥ 1명, 외부 문서는 ≥ 2명)
  - Word 변경 추적 활성
  - 코멘트 (prefix: `nit:`/`q:`/`suggest:`/`blocker:`)
- **stakeholder review** (필요 시)
  - 법무 (계약·외부 공유)
  - 디자이너 (brand)
  - 도메인 전문가 (사실 확인)
- **proofreader** (final 직전, 외부 문서)
  - 맞춤법·typo 전문

## 검토 체크리스트
- [ ] 표지 정보 (제목·작성자·날짜·버전) 정확
- [ ] 목차 본문 일치 (field update)
- [ ] heading 계층 일관 (skip X)
- [ ] 그림·표 번호·캡션 자동
- [ ] cross-reference 동작
- [ ] 참고문헌 모두 인용됨 (역도)
- [ ] 약어 첫 등장 풀이
- [ ] 외국어 표기 일관
- [ ] 맞춤법·띄어쓰기 (F7)
- [ ] 변경 추적 모두 처리
- [ ] 댓글 정리
- [ ] field update (`F9`)
- [ ] 메타·hidden 정보 검사
- [ ] sensitive 정보 마스킹
- [ ] 페이지 번호 일관
- [ ] 머리말·꼬리말 정확
- [ ] alt text·a11y 검사

## forbidden
- self-review 없이 peer
- peer review 0회 외부 공유
- blocker 미해결 다음 단계
- 코멘트 묵살
- review 통과 후 큰 변경 (재검토)
- 변경 추적·댓글 잔존 final
- field 미갱신
- sensitive 정보 잔존
- proofreader 없이 외부 출판
