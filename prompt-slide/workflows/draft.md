## 목적
plan에서 확정한 storyboard를 PowerPoint slide로 옮긴다.

## 절차
1. **template 선택**
   - 사내 standard `.potx` 또는 brand template
   - 16:9 widescreen 확인
   - convention: `design/template`, `branding/brand`
2. **master 점검**
   - color·typography·footer가 brand·a11y 부합 확인
   - 부족하면 master 보강
3. **표지 작성**
   - 제목·발표자·날짜·로고
4. **목차/agenda** (deck > 5장)
   - 본문 섹션 list
5. **각 슬라이드 작성** (storyboard 순서)
   - headline 먼저 (결론 1줄) — `content/headline`
   - 본문은 시각 우선 (차트·이미지·다이어그램)
   - 텍스트는 6x6 rule — `content/bullet`
   - 1 슬라이드 1 message — `structure/slide`
6. **시각 자산**
   - 차트는 PowerPoint 직접 — `content/data`
   - 이미지·icon — `content/visual`
   - 저작권·해상도 확인
7. **결론 슬라이드**
   - big idea 재강조
   - next step·CTA (필요 시)
8. **Q&A·감사**
9. **backup/appendix** (필요 시)
   - hidden slide로 처리 (발표 흐름 영향 X)
10. **발표 노트 작성**
    - 슬라이드별 핵심 script
    - timing 가이드

## 작성 팁
- storyboard와 1:1 매핑. 즉흥 추가 X
- 화려한 디자인 < 명확한 메시지
- 5초 rule: 슬라이드를 5초 보고 메시지 잡히나?
- 동료에 한 슬라이드 보여주고 메시지 추측 테스트
- iteration: draft1 → quick feedback → draft2

## 산출물
- `.pptx` draft (이름: `<topic>_<audience>_<YYYY-MM-DD>_draft.pptx`)
- 발표 노트 포함

## 금지
- storyboard 무시하고 자유 작성
- master 무시하고 직접 디자인
- 1 슬라이드 message 2+
- headline 없이 본문만
- 텍스트만 가득 (시각 무)
- 차트 출처·단위 누락
- 저작권 미확인 이미지
- 6x6 rule 무시
- decorative 슬라이드 (의미 없는 transition·이미지)
- 발표 노트 없이 draft 완료
