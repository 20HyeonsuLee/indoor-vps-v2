## rule
- 팔레트는 **3~5색** 제한:
  - **primary** (brand 1색)
  - **secondary** (보조 1색)
  - **accent/강조** (1색, 데이터 강조용)
  - **neutral** (background·text — 회색조 또는 dark)
  - 의미 색 (success/warning/danger) — 데이터·상태에만
- brand color 우선 (회사 브랜드 가이드 있으면 그것).
- background는 light(흰 또는 매우 옅은) 또는 dark(짙은) 일관. mixed deck X.
- text contrast: WCAG AA — 본문 4.5:1, 큰 텍스트 3:1.
- 강조는 accent 색 1개로. 모든 게 강조면 강조 X.
- chart 색은 categorical (qualitative palette) 또는 sequential (정렬 의미).
- 색만으로 의미 전달 X (icon·라벨 보조).
- dark mode 별도 deck 또는 master variant.

## rule (의미 색)
- success = green, warning = yellow/amber, danger = red, info = blue.
- 단 culturally sensitive 케이스는 청중 컨텍스트 확인.
- 의미 색은 본문 default로 사용 X (데이터·상태에만).

## forbidden
- 6색 이상 팔레트
- random 색 (각 슬라이드마다 다른 강조)
- 배경·텍스트 contrast WCAG 미달
- 빨강·녹색 의존 (색맹 8% 남성)
- gradient 남발 (1 deck에 다양한 gradient)
- background image가 contrast 깨뜨림 (overlay 부족)
- 색이 brand guide 위반
- 같은 슬라이드 안 의미 색 충돌 (success/warning 같이 강조)
- rainbow palette (의미 없는 다색)
- dark + light 슬라이드 혼재 (deck 통일)
