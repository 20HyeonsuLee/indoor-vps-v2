## rule (이미지)
- 이미지는 메시지 보강일 때만. 장식용 stock 이미지 X.
- 해상도 충분 (full-screen이면 1920+ width).
- 비율 유지 (stretch X).
- 배경 제거 또는 일관 (한 deck 다 같은 처리).
- 인물 사진은 시선 방향이 본문 향하게.
- 저작권 확인 (Unsplash/Pexels free 또는 사내 자산).
- alt 대체 텍스트 (a11y).

## rule (icon)
- icon set 1개 통일 (Material/Lucide/Phosphor 등).
- 1 deck = 1 icon family.
- icon 크기 일관 (제목·본문 별로 정해진 크기).
- 의미 명확한 icon만 (애매하면 라벨 동반).
- 단색 또는 2-tone 권장 (deck 색 팔레트 일관).

## rule (스크린샷·mockup)
- 해상도 충분. blur 금지.
- crop은 메시지 영역 강조. 무의미 chrome 제거 (browser bar 등).
- annotation (화살표·강조 box)으로 attention guide.
- mockup frame 사용 (device frame) — 컨텍스트 명시.
- sensitive 정보 마스킹 (이름·email·token).

## rule (signal vs noise)
- 슬라이드 5초 안에 메시지 도달.
- 무관 요소 제거. "이게 정말 필요한가?" 매번 self-test.
- 강조는 1~2개만 (모든 게 강조면 강조 X).
- 색·motion·크기로 attention guide. 그러나 절제.
- 동영상은 짧게 (15초 이하) + autoplay 신중.

## forbidden
- 장식용 stock 이미지 (의미 없음)
- 저작권 미확인 이미지
- 비율 깨진 stretch
- 배경·테두리·effect 무질서 (같은 deck에 다른 처리)
- icon family 혼용 (Lucide + Material 섞임)
- 메시지와 무관한 스크린샷
- sensitive 정보 마스킹 누락
- 모든 요소에 동시 강조 (signal 무력화)
- 동영상 자동재생 + 소리 (a11y·사용자 경험)
- 해상도 부족 이미지 (blurry)
- chrome (browser bar 등) 의미 없이 포함
- 5초 안에 메시지 못 잡는 슬라이드
