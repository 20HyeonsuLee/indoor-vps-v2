## rule
- 회사 brand guide 있으면 그것 SSOT. 없으면 1회 작성해 모든 deck 적용.
- brand 자산:
  - 로고 (color/mono/inverse — 배경별)
  - 색 팔레트 (primary·secondary·accent)
  - 타이포그래피 (heading·body·brand font)
  - 톤·보이스 (formal/friendly/professional)
  - 사용 금지 패턴 (잘못된 사용 예)
- 로고 사용:
  - 안전 여백 (clear space) 준수
  - 최소 크기 명시
  - 색 배경에 inverse 또는 mono
  - 변형·왜곡 금지
- master에 brand 자산 박음. 매 슬라이드 수동 X.
- 외부 발표는 brand 일관 ★★★ (인지·신뢰).
- 내부 deck도 기본 brand 따름 (예외는 의도된 경우만).
- 사내 template 공유 폴더에서 받아 사용.
- brand 변경 시 모든 template 일괄 갱신.

## rule (공동 brand)
- 파트너·스폰서 로고 동반 시 위계 명확 (자사·상대사 크기·위치).
- co-branded deck은 양사 guide 합의.

## forbidden
- 로고 변형·왜곡·색 변경
- 안전 여백 침범
- brand 색·font 무시 (특이 deck 만들기)
- 외부 발표에 brand 누락
- 다른 회사 brand 자산 무단 사용
- 옛 brand (변경 전 로고·색) 사용
- 로고를 배경 이미지로 (가독 ↓)
- 같은 deck에 brand 자산 변형 (1 deck = 1 brand)
- 로고 해상도 부족 (pixelated)
- 사용 금지 패턴 위반
