## rule
- deck은 narrative arc를 따른다. 슬라이드 순서 = 청중의 이해 순서.
- 흔한 arc 패턴:
  - **SCQA** (Situation → Complication → Question → Answer): 컨설팅·문제 해결
  - **Problem → Solution → Proof → Ask**: 세일즈·제안
  - **Why → What → How**: Simon Sinek 패턴, 동기 강조
  - **Past → Present → Future**: 비전·전략
  - **Pyramid (Minto)**: 결론 → 핵심 근거 → 세부. executive 청중
  - **STAR** (Situation/Task/Action/Result): case study
- 청중별:
  - **executive**: top-down 피라미드. 30초 안에 결론·next step
  - **technical**: bottom-up 가능. 가정·detail 먼저
  - **mixed**: 결론 먼저 + appendix로 detail
- 슬라이드 간 transition은 logical (다음 슬라이드 이유가 명확). "다음으로..."가 자연스럽지 않으면 reorder.
- 핵심 메시지(빅 아이디어)는 deck에서 ≥ 3회 등장 (intro/본문/결론).
- callback 패턴: intro에서 던진 question을 결론에서 회수.
- pacing: 무거운 슬라이드 후 가벼운 슬라이드 (강·약). 같은 톤 5장 연속 X.
- section divider 슬라이드로 transition 명시 (긴 deck).

## forbidden
- 슬라이드 순서가 의식의 흐름 (random)
- "이제 다른 주제..." 없는 점프
- 결론을 마지막에만 (executive 청중에는 fail)
- callback 없이 intro에서 던진 question 방치
- 같은 무게 슬라이드 연속 (지루)
- section divider 없이 30+ 슬라이드
- arc 패턴 혼합 (한 deck = 한 arc)
- detail 먼저 + 결론 뒤 (executive)
- 핵심 메시지 1회만 등장 (반복 강조 필요)
- transition 누락 (이전 슬라이드와 무관한 시작)
