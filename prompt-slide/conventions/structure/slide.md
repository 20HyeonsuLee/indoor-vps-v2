## rule
- 1 슬라이드 = **1 핵심 메시지**. 메시지 2개면 슬라이드 분리.
- 표준 zone:
  - **headline** (위, 큰 글씨): 슬라이드의 결론을 1줄로 (`content/headline.md`)
  - **body** (중앙): 메시지를 뒷받침하는 시각/텍스트 (1~3 element)
  - **footer** (아래): 페이지 번호·로고·메타 (master에서 자동)
- 시각 우선: 글보다 차트·다이어그램·이미지가 메시지 전달에 더 효과적이면 그쪽.
- 텍스트 양:
  - bullet 5개 이하 (6 줄 × 6 단어 = "6x6 rule" 권장)
  - 문장은 ≤ 12 단어
  - 연속 줄글 슬라이드 X (그건 word 문서)
- 여백은 결정적. 화면 가장자리 5~8% safe area, element 간 명시적 gap.
- 정렬: 좌측·중앙·우측 명확. 어중간한 위치 X.
- z-index 의식: 배경 → 본문 → 강조 → callout.
- 1 슬라이드가 5초 안에 읽혀야 함 (signal-to-noise).
- 슬라이드 비율: **16:9 widescreen** 표준. 4:3은 레거시 환경 한정.

## forbidden
- 한 슬라이드 메시지 2개 이상
- 글머리표 7개 초과
- 한 슬라이드에 글자만 가득 (text wall)
- 너무 작은 font (본문 < 18pt — design/typography 참조)
- 정렬 무질서 (element가 grid 밖에서 떠다님)
- 여백 누락 (가장자리에 글자 붙음)
- 한 슬라이드에 3개 이상 색조 사용
- background image가 텍스트 가독성 방해
- 슬라이드 안 4 이상 columns
- headline 없이 본문만 (메시지 추측 강요)
- 같은 슬라이드 안 font 3종 이상 혼용
- 화면 영역 50% 초과 빈 공간 (의도된 minimalism 제외)
- 6x6 rule 초과 + 시각 보조 없음
