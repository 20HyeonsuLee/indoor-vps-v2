## rule
- 모든 이미지·차트·아이콘에 **alt text** (장식이면 빈 alt).
- 색만으로 의미 전달 X (icon·label 보조).
- color contrast 4.5:1 (본문) / 3:1 (큰 텍스트·UI).
- 폰트 ≥ 18pt (그 이하 X — `design/typography.md`).
- reading order 명확 (스크린리더). PowerPoint 보기 > 선택 창에서 확인.
- 슬라이드 제목은 표지 외 모두 unique (스크린리더 navigation).
- 자동 재생 영상·소리 X.
- flashing > 3Hz 금지 (간질 유발).
- 표는 헤더 행 명시 (스크린리더 인식).
- 슬라이드 노트에 핵심 내용 (시각 못 보는 청중 보조).
- subtitle/caption 제공 (영상·발표 녹화).
- 인쇄 핸드아웃은 흑백에서도 의미 전달.

## 검증
- PowerPoint 접근성 검사 (검토 > 접근성 검사) 활용.
- 흑백 인쇄 미리보기로 색 의존 점검.
- 다양한 거리·각도에서 가독성 확인.
- 스크린리더(NVDA·VoiceOver) 통과.

## forbidden
- alt text 누락
- 색만으로 상태 표시 (success/error)
- contrast WCAG 미달
- 본문 < 18pt
- reading order 무질서
- flashing motion
- 자동재생 + 소리
- 표 헤더 미지정
- 슬라이드 노트 없이 시각 위주 발표
- caption 없는 영상
- 같은 제목 슬라이드 여러 개 ("Slide 1", "Slide 2")
- decorative element가 reading order에 포함
