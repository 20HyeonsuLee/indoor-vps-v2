## rule (검토 6 축)
1. **메시지**: 슬라이드마다 1 message 명확? big idea가 deck 끝에 기억되나?
2. **flow**: narrative arc 일관? transition 자연?
3. **시각**: chart·이미지가 메시지 보강? signal-to-noise 양호? chartjunk 없음?
4. **디자인**: brand·typography·color·layout 일관? grid align?
5. **a11y**: alt text·contrast·font 크기·reading order?
6. **품질**: 오타·맞춤법·날짜·숫자·약어 풀이?

## 단계별 review
- **author self-review** (draft 완료 후): 모든 슬라이드를 5초씩 보고 메시지 잡힘 확인
- **peer review** (≥ 1명): 6 축 점검 + 의견
- **stakeholder review** (필요 시): 결정권자·디자이너·법무 등
- **dry-run** (큰 발표): 실제 timing + 청중 시뮬레이션

## 검토 체크리스트
- [ ] 표지 정보 (제목·발표자·날짜·로고) 정확
- [ ] 목차/agenda 본문 일치
- [ ] 모든 슬라이드 headline = 결론 (주제 X)
- [ ] 1 슬라이드 1 message
- [ ] 차트 출처·단위 명시
- [ ] 표 alignment·헤더 명확
- [ ] 이미지 저작권 OK
- [ ] 약어 첫 등장 풀이
- [ ] 색 contrast WCAG AA
- [ ] 폰트 embed (다른 PC 호환)
- [ ] 슬라이드 번호 일관
- [ ] 결론 슬라이드 next step
- [ ] Q&A·감사 슬라이드
- [ ] backup 슬라이드 hidden (필요 시 노출)
- [ ] sensitive 정보 마스킹
- [ ] dry-run timing 맞춤
- [ ] 발표자 노트 작성

## forbidden
- self-review 없이 다음 단계
- peer review 0명으로 외부 발표
- dry-run 없이 큰 발표 (10분 이상)
- 검토 코멘트 묵살 (해결 또는 토론)
- 마지막 순간 큰 변경 (검토 시간 부족)
- "small typo만 고치자" 후 큰 수정
- 검토자 의견 익명 처리 (책임 추적 어려움)
- review 통과 후 final에서 새 슬라이드 추가
- backup 슬라이드를 본문에 섞은 채 final
- 사실 검증 없는 데이터 (출처·계산 확인)
